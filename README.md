# 평안이 (Pyeongani)

잔잔한 물결을 닮은 휴식 친구, **평안이** 캐릭터 소개 웹페이지입니다.

🔗 https://ypcs.web.app

---

## ⚠️ 공식 캐릭터가 아닙니다

평안이는 **양평군의 공식 캐릭터가 아닙니다.** 양평을 아끼는 마음으로 만든 **비공식 창작 캐릭터**이며,
양평군 및 양평군의 공식 캐릭터인 양춘이와는 공식적인 관계가 없습니다.

## 이름

양평군에는 원래 양춘이가 있습니다. 그런데 양춘이는 '양평'의 '양'만 담고 있었죠.
그래서 '평'을 맡을 친구를 만들어 보았습니다. 둘이 나란히 서야 비로소 **양평**이 됩니다.

이름에는 양평군에 살고 지나는 모든 존재 — 사람뿐 아니라 강물, 나무, 새, 바람까지 —
평안하기를 바라는 마음을 담았습니다.

## 구성

정적 페이지 하나입니다. 빌드 과정이 없어 `index.html`을 브라우저로 바로 열 수 있습니다.

```
index.html                 벤토 그리드 소개 페이지 (CSS·JS 인라인)
assets/
  scenes/   s01–s34.jpg    장면 34컷 (800px로 줄인 웹용)
  sheet/                   캐릭터 시트에서 떼어낸 조각들
                           portrait · turnaround · faces · poses · details · full
평안이캐릭터모음/            원본 PNG 1254px (배포에는 포함되지 않음)
```

페이지에 쓰인 색 여섯 가지는 캐릭터 시트의 `05 색상`에서 그대로 가져왔습니다.

| 이름 | 값 |
| --- | --- |
| 하늘물 블루 | `#8DD3F0` |
| 평온 민트 | `#A8DCD2` |
| 따스한 아이보리 | `#FCF3E3` |
| 연꽃 핑크 | `#F5B3C3` |
| 외곽선 네이비 | `#16344F` |
| 발 딥틸 | `#2C5F5C` |

## 배포

Firebase Hosting으로 배포합니다.

```bash
firebase deploy --only hosting
```

`firebase.json`의 `ignore` 규칙이 원본 PNG 폴더를 제외하므로, 배포되는 용량은 약 2.6MB입니다.
